## 🌟 Features Overview

### 1. Public Portal & Institutional Landing Page
- **Hero Carousel**: High-impact campus, lab, and online desk visuals with admission action triggers.
- **Academic Course Modal**: Detailed curriculum for **Computer Office Application** (3-Month & 6-Month courses) with Government Technical Board syllabus.
- **Official Admission Form**: Fully styled Bangladeshi institutional admission form with photo upload, guardian info, board exam records, and printable receipt.
- **Job Portal / Notice**: Live circular board featuring verified government circulars (DPE, Railway, DGHS, Bank), notice PDF viewer, and direct apply triggers.

### 2. Multi-Role Authentication
- **Student Login**: Access to course materials, typing speed benchmarks, fee accounts, and notices.
- **Applicant Login & Registration**: Track submitted applications, fees, and downloadable admit cards.
- **Institute / Admin Login**: Dedicated administrator control panel.

### 3. Student Dashboard
- **Course Fee & Accounts**: Real-time display of **Total Course Fee (মোট ফি)**, **Total Paid (জমা টাকা)**, and **Due Balance (বাকি টাকা)**.
- **Practice Drive**: Laboratory practice assignments (MS Word, Excel, PowerPoint, Access).
- **Official Notices**: View and download official institute announcements and PDF attachments.

### 4. Applicant Dashboard
- **Application Tracking**: Real-time verification status for applied job circulars.
- **Admit Card Downloads**: Download verified exam admit cards and submitted copies.
- **Circular Updates**: Direct access to newly published notices and exam schedules.

### 5. Institute Admin Control Panel
- **Notice Board Control & PDF Upload**: Upload official circulars with embedded PDF files for instant student and public download/print.
- **Student Profile, Fee & Password Management**: View/edit full student records, adjust total/paid fees with quick payment installments, and reset student login passwords.
- **Applicant Control & Password Management**: Manage applicants, verify fee status, issue admit cards, and reset applicant passwords.

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/<your-username>/<your-repo-name>.git

# Navigate to the project directory
cd <your-repo-name>

# Install dependencies
npm install

# Start local development server
npm run dev
```

Build for production:
```bash
npm run build
```
